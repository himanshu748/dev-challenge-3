Four calls, one pipeline.

Every step is a single API call. The model writes, the local store keeps score.

  1. 1

    Initialize the workspace

    Name it and go. State lives in a local JSON store, no accounts, no external services.

  2. 2

    Publish a job

    A rough brief becomes a polished description with responsibilities, requirements, and nice-to-haves.

  3. 3

    Screen a candidate

    The resume is scored 1 to 10 against the stored job description, with strengths, gaps, and a recommendation.

  4. 4

    Send the offer

    A complete offer letter is drafted and the candidate advances to the final stage automatically.
